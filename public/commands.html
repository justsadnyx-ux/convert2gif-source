Commands

Every command works as a prefix command (.cmd) and, where noted, as a slash command (/cmd).

.gif /gif

Turn an image or URL into a real static GIF file — images only.

  • Attach an image to your .gif message, or reply to a message that has one.
  • Convert by URL: .gif https://example.com/image.png, or slash /gif url:.
  • Images come out as a clean static GIF — a real .gif file with no motion.
  • Existing .gif files pass through unchanged.
.imginfo /imginfo

  • Total GIFs converted and servers running Convert2GIF.

  • Also links to the web converter.

Rate limits

To keep the service free and responsive:

  • GIF conversions: 3 per user per 10 minutes via the bot.
  • Other commands: 5 per user per 15 seconds.
  • Web converter: 10 conversions per 10 minutes per IP.
