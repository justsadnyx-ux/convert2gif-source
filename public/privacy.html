Privacy Policy

Last updated: September 11, 2026

This Privacy Policy explains how Convert2GIF ("the service") handles data when you use the Convert2GIF Discord bot or convert2gif.pages.dev.

Discord Bot — what it processes

The bot can be used in any server or DM, but every command requires membership of the Convert2GIF server. It accepts images only (PNG, JPG, GIF) and turns them into static GIF files. When you use a command, the following data is processed:

  • Message content — read only to recognize the command (e.g. .gif, /gif) and immediately discarded.
  • Attached images — fetched and converted in memory on Cloudflare's edge; the bytes are never stored and the resulting GIF is the only thing retained (as your Discord attachment).
  • User IDs — used temporarily for rate limiting (3 GIFs per 10 minutes) and membership verification.
  • Aggregate counters — total conversions and server count are stored in Cloudflare KV and shown only in aggregate on the bot's stats.

Many slash-command replies are ephemeral — only you can see them. We do not sell, share, or publish any personal data.

Abuse moderation

Inside the Convert2GIF server the bot performs automated moderation: messages containing banned language, scam links, mention-spam, and NSFW images are removed. Disallowed reactions are removed. A short log of each action (author, channel, full message text) is recorded in the server's private #abuse-logs channel, visible only to server staff. This log exists solely to keep the server safe.

Image logging

Every image posted in the Convert2GIF server is logged (filename, poster, channel, and message link) to the private #abuse-logs channel for moderation records. Images are not stored outside Discord.

Web Converter (this site)

The web converter runs entirely in your browser. Files are processed locally on your device and are never uploaded to our servers. The web converter is currently temporarily disabled for maintenance. The site does not use cookies or third-party trackers.

Rate Limiting Data

To enforce rate limits we keep a short-lived counter tied to your user ID (Discord) or connection IP (web). Counters reset automatically after a short window and are used only for rate limiting.

Infrastructure & Retention

  • Runs on Cloudflare Workers & Pages; Cloudflare processes standard request metadata (e.g. IP) per its own policy.
  • Converted files: not retained.
  • Rate limit counters: retained only for the active window.
  • Abuse log entries: retained in the private #abuse-logs channel until manually cleared by staff.
  • Aggregate statistics: retained indefinitely in aggregated, non-personal form.

Your Rights

We store no personal data beyond transient counters. Abuse-log entries are limited to content you chose to post in the Convert2GIF server. To request removal, contact the server owner in the Convert2GIF server.

Changes

We may update this Privacy Policy from time to time. Changes will be posted on this page.
